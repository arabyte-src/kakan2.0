# KAKAN

A small static site exploring the food, places, and traditions of the Bicol Region.

## Project structure

- `src/index.html` - page markup
- `src/style.css` - styles and responsive layout
- `src/script.js` - dish filtering, search, and interactive details
- `assets/` - images and favicon

## Run locally

From the project root, start a simple local server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000/src/](http://localhost:8000/src/) in a browser.

The site is a static frontend and does not require dependencies or a build step.
